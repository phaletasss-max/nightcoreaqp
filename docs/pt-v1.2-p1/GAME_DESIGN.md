# PROPÓSITO

La gamificación existe para aumentar la participación del usuario sin convertir la plataforma en un juego competitivo.

El objetivo es fomentar la exploración, la constancia y la participación positiva dentro de la comunidad.

Nunca debe incentivar conductas abusivas o repetitivas únicamente para obtener recompensas.

---

# FILOSOFÍA

Toda recompensa debe reconocer una acción significativa.

La calidad de la participación tiene prioridad sobre la cantidad.

No existen mecánicas Pay To Win.

No existen ventajas funcionales por tener mayor reputación.

La progresión representa experiencia dentro de Glitch AQP.

Nunca superioridad frente a otros usuarios.

# ASCENSO

La reputación aumenta mediante acciones variadas.

Escuchar música.

Crear playlists.

Guardar favoritos.

Descubrir nuevos artistas.

Participar en eventos.

Responder encuestas.

Interactuar con NΞON.

Visitar la plataforma de forma constante.

Nunca aumentar únicamente por permanecer conectado.

---

# LÍMITES

El sistema debe evitar el abuso.

No otorgar reputación por acciones repetitivas realizadas en pocos segundos.

Aplicar límites diarios cuando sea necesario.

Detectar automatización evidente.

---

# PÉRDIDA DE REPUTACIÓN

Por defecto, la reputación no disminuye.

Excepciones.

Sanciones graves.

Abuso del sistema.

Uso automatizado.

Manipulación de estadísticas.

Estas acciones deberán quedar registradas mediante auditoría.
