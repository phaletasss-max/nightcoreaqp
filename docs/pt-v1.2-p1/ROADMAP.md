# PROPÓSITO

Este documento describe la visión a largo plazo de Glitch AQP.

No representa una lista rígida de tareas.

Representa la dirección estratégica del proyecto.

Toda nueva funcionalidad deberá alinearse con este documento.

---

# VISIÓN

Glitch AQP no pretende ser únicamente una página para escuchar música.

Su objetivo es convertirse en una comunidad digital inspirada en la cultura Nightcore, Happy Hardcore, Scenecore y la nostalgia de Internet entre los años 2000 y 2015.

La plataforma deberá sentirse como un lugar al que los usuarios quieran regresar.

---

# MISIÓN

Crear la mejor comunidad Nightcore de habla hispana.

Combinar música.

Tecnología.

IA.

Todo dentro de una única plataforma.
